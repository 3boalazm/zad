# Product Principles

ZAD is an Arabic-first Islamic worship companion with daily worship utilities and specialist educational/seasonal resources. Repository reconnaissance found 86 top-level HTML pages plus shared JavaScript, CSS, PWA assets, content datasets and a TypeScript API. Product areas include prayer times/Qibla, Quran, adhkar, counters, progress, Arafah/Hajj, zakat/fiqh guides, family/kids, media/library, AI and optional sync. Page existence does not prove a feature is complete. Likely needs (inferred, not user-researched): quick routine resumption, offline access, trustworthy references, private progress and optional cross-device continuity.
