# Design Tokens

Design evidence: CSS custom properties for background/card/ink/muted/border/shadow, green/gold brand roles and button/card roles; dark, OLED black and special excuse modes exist in CSS. Thmanyah Sans/Serif and Amiri Quran fonts are bundled. Shared `js/design-system.js` and token modules exist, alongside duplicated overrides and page-specific styles. This is not a formal component-library package. Exact computed styles, all responsive breakpoints and current contrast were not inspected in a browser.
