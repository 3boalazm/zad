# Portfolio Case Study

## ZAD — a local-first companion for everyday worship

ZAD combines daily worship tools and specialist Islamic learning in an Arabic-first PWA. The product challenge evidenced by the implementation is balancing breadth with reliability and religious trust across intermittent connectivity.

**Experience:** public pages expose prayer setup, Quran plans, adhkar, Hajj, zakat, settings and optional registration. Production health and API route listing work; interactive workflows were not tested. The observed date conflict and prayer error state are limitations, not accomplishments.

**System:** static pages and service worker; localStorage plus Dexie; optional Express/PostgreSQL sync; light/dark/OLED foundations; seven locale bundles. Offline is selective and not end-to-end verified. AI integration is source-visible but not safety-certified.

**Role/outcomes:** owner confirmation required for personal role, collaboration, inherited work, AI assistance and dates. No engagement/performance metrics are available; none are claimed.
