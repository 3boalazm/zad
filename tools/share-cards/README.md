# استوديو المشاركة — أمثلة

هذه صور مُولَّدة من `js/ui/share-studio.js` نفسه (نفس المحرّك الذي يعمل في المتصفح)،
بدقة ٢٧٠×٣٣٧ لكل صورة هنا نسخة مصغّرة من ١٠٨٠ بيكسل.

| الملف | القالب | اللوحة | المقاس |
|---|---|---|---|
| `01-verse-emerald.jpg` | آية (محراب + ۞) | زمردي | بورتريه ٤:٥ |
| `02-dua-ivory.jpg` | دعاء | ورقي | بورتريه ٤:٥ |
| `03-hadith-midnight.jpg` | اقتباس/حديث | ليلي | مربع |
| `04-achievement-sand.jpg` | إنجاز (شبكة أرقام) | رملي | بورتريه ٤:٥ |

لتوليد صور جديدة بنفس الجودة داخل المتصفح:

```js
ZadStudio.open({ kind: 'verse', eyebrow: 'آية اليوم', body: '…', source: '…' });
// أو بلا واجهة:
const blob = await ZadStudio.toBlob({ kind: 'dua', title: 'دعاء', body: '…' });
```
