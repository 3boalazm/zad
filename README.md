# زاد (ZAD) — رفيقك في العبادة والخير

> تطبيق ويب تقدمي (PWA) إسلامي يعمل بدون إنترنت (Offline-First)، رفيق يومي للعبادة والذكر مع أدلة متخصصة لمواسم الخير وبخاصة عشر ذي الحجة ويوم عرفة ومناسك الحج. يجمع بين مواقيت الصلاة، الورد القرآني، الأذكار الموثّقة، المسبحة الرقمية، جدول العبادات اليومي، ونظام مزامنة سحابي اختياري عبر واجهة برمجية آمنة مبنية بـ Node.js/TypeScript وقاعدة بيانات PostgreSQL.

---

## 🧭 نظرة عامة على المعمارية (Architecture Overview)

المشروع يتألف من شقّين متكاملين:

1. **الواجهة الأمامية وتجربة المستخدم (Frontend PWA):**
   - تطبيق ويب ثابت (Static Web App) مبني بـ HTML5 / Vanilla JavaScript / CSS حديث ونظيف.
   - يعتمد على مبدأ **Offline-First**: يعمل التطبيق بكامل وظائفه الأساسية (مواقيت الصلاة، القرآن، الأذكار، التكبير، تتبع العبادات) دون الحاجة لاتصال بالإنترنت عبر Service Worker (`sw.js`).
   - التخزين المحلي يتم عبر `Dexie.js` (IndexedDB Schema v3) في `js/storage.js` مع `localStorage` لحفظ التفضيلات والحالات اللحظية.
   - يدعم 3 أوضاع بصرية: الفاتح (Light)، والداكن (Dark)، وشاشات الأموليد (OLED Pure Black).
   - متوافق مع معايير الوصول العالمية (WCAG 2.1 AA) ومحسّن لشاشات الهواتف مع احترام الـ Safe Areas في iOS/Android.

2. **الواجهة الخلفية وخدمات المزامنة (`api/` Backend):**
   - خادم Express 4 مكتوب بـ TypeScript 5 يعمل على Node.js ≥ 18.
   - قاعدة بيانات PostgreSQL 16 مع نظام هجرات تدريجي (`api/db/migrations/`).
   - نظام مصادقة آمن يعتمد على كوكيز الجلسات `HttpOnly` وتشفير كلمات المرور بـ `argon2id` وتخزين تجزئة الرموز بـ `SHA-256`.
   - محرك مزامنة عبادات موثوق (`/api/v1/worship`, `/api/v1/sync`) يدعم القفل الاستشاري `pg_advisory_xact_lock` ومعالجة تضارب مفاتيح الـ Idempotency المعزولة لكل مستخدم.

## 🚀 التشغيل والاختبار (Quick Start & Testing)

### 1. تشغيل الواجهة الأمامية (Frontend)
تطبيق الويب ثابت ولا يتطلب أي عملية بناء مسبقة:
```bash
# تشغيل خادم محلي اختباري (باستخدام Python أو أي خادم ملفات ثابتة)
python3 -m http.server 8080
# افتح المتصفح على: http://localhost:8080
```

### 2. تشغيل واجهة الـ API الخلفية (Backend)
```bash
cd api

# تثبيت الاعتماديات
npm ci

# فحص توافق الأنواع (Type-check)
npm run typecheck

# بناء الكود المصدري (Build)
npm run build

# تشغيل الاختبارات الآلية (Unit & Integration Tests)
npm test

# تشغيل الخادم في وضع التطوير
npm run dev
```

## 🔒 الأمان والموثوقية (Security & Reliability)

- **حماية الأسرار:** لا يتم تضمين أي مفاتيح تشغيل أو أسرار حساسة في شجرة التتبع Git. يتم الاعتماد على متغيرات البيئة عبر `.env.example`.
- **سلامة الجلسات:** كوكيز الجلسات تحمل أعلام `HttpOnly`, `SameSite=Lax`, وتعتمد على رموز عشوائية 256-bit مخزنة كـ SHA-256 hashes في قاعدة البيانات.
- **تأمين ضد هجمات الـ Replay والـ Concurrency:** استخدام الـ Advisory Transaction Locks لمنع تضارب الكتابة المتزامنة لسجلات المستخدم، مع عزل مفاتيح الـ Idempotency لكل حساب على حدة لمنع أي تداخل بين المستخدمين.
- **التحقق من صحة المدخلات:** تحقق صارم على كافة حقول التسجيل والمزامنة وتأمين الاستعلامات بنظام الاستعلامات المعلمة (Parameterized Queries) لمنع SQL Injection.
