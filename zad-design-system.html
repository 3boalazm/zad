01

مبادئ التصميم

أربعة مبادئ تحكم كل قرار — من اختيار درجة الأخضر إلى حركة زرّ التسبيح.

🕊️ سكينة قبل الزخرفة

المحتوى الشرعي هو البطل. التدرجات واللمسات الذهبية خادمة للنص لا منافسة له؛ لا نيون، لا تشتيت أثناء العبادة.

📿 عبادة بلا احتكاك

كل مهمة يومية (ذكر، ورد، صلاة) تُنجز في ≤3 نقرات، وتعمل كاملة بلا إنترنت — Offline-First مبدأ تصميم لا مجرد تقنية.

🌗 نورٌ وظلمةٌ بكرامة

الداكن وOLED ليسا «عكس ألوان» بل إعادة صياغة دلالية كاملة لكل توكن، بتباين AA موثّق ومُختبَر حياً.

🧒 من الطفل إلى الحاجّ

نظام واحد يتفرع لهويات فرعية (أطفال، حج، رمضان) دون أن ينكسر — توكنز مشتركة وشخصية محلية مقصودة.

🏗️ معمارية التوكنز — ثلاث طبقات (Single Source of Truth)

درسٌ مدفوع الثمن: تكرار نفس الـHex يدوياً في أكثر من ملف كان سبب أغلب أخطاء الثيمات تاريخياً. الحل المعتمد الآن:

① Primitives

--primitive-green-900 قيم خام ثابتة عمداً لا تتفاعل مع الثيم — لأنها خلفيات صلبة تحت نص أبيض (أبيض فوق أخضر الداكن الساطع = 1.85:1 فقط!).

② Semantic

--bg / --ink / --green-deep / --gold تتبدل دلاليًا حسب الثيم. كل الشاشات تستهلك هذه الطبقة فقط.

③ Component

--button-primary-bg / --card-border / --progress-fill-* عقدٌ بين الدلالي والمكوّن — alias صفر تغيير بصري، يمنع انجراف المكونات الشبيهة.

اضغط أي بطاقة لنسخ الـHex. الهوية: أخضر غابيّ عميق (السكينة والنمو) × ذهبيّ دافئ (النور والقيمة) فوق رملٍ محايد.

✅ افعل

  • استهلك Semantic دائماً؛ Primitives للأسطح الصلبة فقط.
  • الذهبي للتمييز والإنجاز — لا للنصوص الطويلة.
  • اختبر أي لون جديد في الثيمات الثلاثة معاً.

⛔ لا تفعل

  • لا تكتب Hex خاماً داخل صفحة — ستفوّت إصلاحات الثيم.
  • لا تضع نصاً أبيض فوق --green-deep في الداكن.
  • لا تستخدم الأحمر إلا للخطر/الخطأ فعلياً.

07

الإتاحة والاتجاه واللغات

♿ WCAG 2.1 AA

تباين موثّق بالأرقام (مثال زر الخطر: 5.44:1 فاتح · 6.68:1 داكن · 7.63:1 OLED)، أهداف لمس ≥44px، تركيز مرئي، حوارات بـ Escape واسترجاع تركيز، ووضع إتاحة مخصص (تباين أعلى + خط أكبر).

⇄ RTL حقيقي لا مرآة عمياء

إصلاح جذري موثّق: إزالة فرض direction:rtl بالـCSS الذي كان يهزم تبديل اللغة صامتاً، والتحوّل إلى Logical Properties ‏(inline-start/end) — الواجهة تنعكس فعلياً في LTR لأول مرة.

🌍 ٤ لغات

العربية (افتراضي RTL) · English · Français · اردو/تركية عبر lang.js — النص القرآني يبقى Amiri دائماً مهما تبدّلت لغة الواجهة.

08

التوكنز — للنسخ المباشر

مقتطف من مصدر الحقيقة css/style.css — الصق وابدأ:

/* Primitives — never theme-reactive */
--primitive-green-900: #0e3b2e; --primitive-green-700: #1a5d47;
--primitive-green-500: #2a7a5f; --primitive-gold-500: #c9a14a;
/* Semantic (light) */
--bg:#f5f4f0; --card:#fff; --ink:#1a1a18; --gold:var(--brand-gold);
/* Component contract */
--button-primary-bg:var(--brand-deep); --card-radius:18px;
--progress-fill-from:var(--green-soft); --progress-fill-to:var(--gold);
/* Layers */ --z-sidebar:100; --z-overlay:500; --z-toast:9999;

📏 حوكمة النظام

أي لون/مكوّن جديد يمرّ بـ: توكن ← ثيمات ٣ ← تباين AA ← توثيق هنا. ممنوع الـHex الخام والـz-index الرقمي المجهول داخل الصفحات. الهويات الفرعية (أطفال/مواسم) انحراف مقصود وموثّق لا خطأ.
